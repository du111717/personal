# 自我介绍 + 学习笔记个人网站

这是一个纯前端个人网站模板，包含自我介绍、学习方向、学习笔记、成长时间线和联系区域。

## 运行方式

直接双击打开 `index.html` 即可预览。

如果你希望用本地服务预览，也可以在当前目录运行：

```bash
python -m http.server 5173
```

然后访问 `http://localhost:5173`。

## 修改内容

- 页面文字主要在 `index.html` 中修改。
- 颜色、间距、动效主要在 `styles.css` 顶部的变量和对应注释区域修改。
- 菜单展开、滚动出现、笔记筛选、进度条动效在 `script.js` 中。
- 首屏图片位于 `assets/hero-workspace.png`，可以替换为同名图片。
